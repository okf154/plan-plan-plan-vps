## 补货时的下单流程

### 1. 提前准备账户信息

补货出现后，临时注册账户、验证邮箱、填写付款信息会浪费时间。提前准备好常用邮箱和可用支付方式，至少要确保可以正常完成结账。

### 2. 先确认方案，再确认机房

不要看到名称相似就直接下单。确认产品名称、内存、硬盘、月流量和可选机房是否与你需要的版本一致。特别是 THE PLAN、THE PLAN v2 等名称，不能只靠标题判断。

### 3. 检查价格和续费周期

订单页中的价格比文章截图更重要。重点查看：

- 当前应付金额；
- 计费周期；
- 续费金额；
- 是否自动续费；
- 优惠是否只适用于首单；
- 优惠是否影响续费；
- 是否包含税费或支付手续费。

不要把第三方页面中的优惠码直接当成官方现行优惠。只有结账页实际接受并重新计算金额的优惠，才算对当前订单有效。

### 4. 付款前确认退款条件

如果购买的是限量版，建议在付款前再次查看服务条款。尤其要留意 IP 黑名单、流量使用量、账户违规和退款后数据删除等条件。官网目前提供 30 天退款政策，但它有明确限制，并非所有情况都能退款。

### 5. 开通后先做基础检查

VPS 开通后，不要马上把生产环境全部迁过去。可以先完成这些检查：

1. 登录 KiwiVM；
2. 确认操作系统和内核；
3. 查看 CPU、内存、磁盘和流量统计；
4. 测试 SSH 登录；
5. 检查 rDNS 设置；
6. 确认快照或备份功能；
7. 测试需要使用的端口和服务；
8. 观察 IP 是否适合邮件、网站或其他业务。

搬瓦工官网提供完整 root 权限、rDNS、KiwiVM 管理面板以及 PPP/VPN 支持，但服务属于自管理 VPS。也就是说，主机商提供基础设施，系统和应用层面的维护仍由用户负责。
